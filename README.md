# 게임 제작 과제 기획서
- 게임 제목: Stone Age
- 장르: 생존 액션
- 예상 플레이 시간: 10분 이하

---

# 1. 게임 개요

## 1-1. 게임 소개

- 제한된 전장 안에서 다가오는 적을 처치하고 피하며 제한 시간 동안 생존하는 게임

## 1-2. 게임 목표

- 제한 시간인 10분 동안 생존
- 처치 시 획득 가능한 아이템을 통해 플레이어 강화

## 1-3. 게임 특징

- 제한된 사각형 전장
- WASD를 이용한 이동
- 자동으로 실행되는 공격
- 주어진 시간 동안 계속해서 생성되는 적
- 시간의 흐름에 따라 적의 수가 증가
- 아이템 획득을 통한 플레이어 강화로 적의 공세를 방어

---

# 2. 게임 진행

## 2-1. 전체 게임 흐름

게임 시작
→ 무기 선택
→ 전장 입장
→ 적 소환
→ 전투
→ 게임 오버 / 게임 클리어 

## 2-2. 게임 진행 순서 및 UI 구성
1. 게임 시작
2. 무기 선택
3. 전투 시작
4. 플레이어로부터 일정 거리 이상 떨어진 위치에서 적이 생성
5. 자동 공격과 이동을 통해 적의 접근을 피하며 제한 시간 동안 생존
6. 플레이어 HP가 0일 경우 게임 오버
7. 제한 시간까지 생존 시 게임 클리어

### 시작 화면
- 게임 제목 표시
- 게임 시작/종료 버튼 표시

### 인게임 화면
- 3 종류의 무기 선택창 표시
- 선택 직후 바로 적이 소환되며 게임 진행
- 현재 남은 시간 표시
- 현재까지 처치한 적의 수 표시
- 아이템 획득으로 강화된 플레이어의 공격력, 공격 범위, 공격 속도 스탯 표시
- 플레이어 HP 표시
- 적에겐 피격 모션만 존재하며 체력바 표시 X

### 게임 오버 화면
- 게임 오버 표시
- 처치한 적의 수 표시
- 남은 시간 표시
- 메인 화면 / 다시하기 버튼 표시

### 게임 클리어 화면
- 게임 클리어 표시
- 총 처치한 적의 수 표시
- 총 획득 아이템 수 표시
- 메인 화면 / 다시하기 버튼 표시

# 4. 플레이어

## 4-1. 플레이어 기본 능력치

| 능력치 | 설명 |
|---|---|
| HP | 플레이어의 현재 체력 |
| 공격력 | 적에게 가하는 피해량 |
| 공격 범위 | 원거리 공격이 발사되는 거리 / 근거리 공격의 판정 범위 |
| 공격 속도 | 공격 발생 간격 |

---

## 4-2. 플레이어 피격

- 적과 충돌하면 HP 감소
- 피격 후 0.1초의 무적 타임 존재
- HP가 0이 되면 게임 오버

---

# 5. 무기 시스템

게임 시작 시 3개의 무기 중 하나를 선택

## 5-1. 원거리 무기

- 투사체를 발사하는 원거리 공격
- 공격 범위 내에서 플레이어와 가장 가까운 적을 우선적으로 자동 공격
- 투사체 명중 시 피해

## 5-2. 근거리 무기

- 플레이어 이동 방향으로 무기를 휘두르는 근거리 공격
- 공격 범위 내 모든 적에게 피해
- 일정한 공격 속도로 자동으로 공격

## 5-3. 번개 공격

- 공격 범위 내의 적 중 하나를 무작위로 선택
- 선택된 적에게 번개를 떨어뜨리고, 해당 적 주변에 범위 피해

---

# 6. 적 시스템

## 6-1. 일반 몹

- 플레이어를 추적
- 플레이어보다 느린 이동 속도
- 다수의 적이 지속적으로 생성
- HP가 0이 되면 처치

## 6-2. 특수 몹

- 일반 몹보다 훨씬 큰 크기
- 일반 몹보다 느린 이동 속도
- 일반 몹보다 높은 HP
- 플레이어의 이동을 방해하고 압박하는 역할

## 6-3. 적 생성

- 몹끼리 충돌하며 서로 겹치지 않음
- 플레이어로부터 일정 거리 이상 떨어진 위치에서 생성
- 생성 위치는 무작위로 결정
- 시간이 지날수록 생성되는 적의 수가 증가

---

# 7. 아이템 시스템

## 7-1 아이템 종류

| 아이템 | 효과 |
|---|---|
| 회복 아이템 | 플레이어 HP 회복 |
| 강화 아이템 | HP를 제외한 능력치 한 가지를 선택해 스탯 증가 |

## 7-2 아이템 카운트

- 획득한 아이템 수를 기록
- 게임 오버/클리어 화면에서 총 획득 아이템 수를 표시

---

# 8. 전장

## 8-1. 맵 구성

- 화면 전체를 사용하는 사각형 형태의 전장
- 플레이어는 전장 밖으로 이동할 수 없음

## 8-2. 전투 환경

- 한정된 공간에서 지속적으로 적 몹이 생성
- 시간의 흐름에 따라 생성 빈도 / 생성 수 증가
- 플레이어는 이동하면서 적을 피하고 처치하며 생존
